วิธีนำไฟล์ zip นี้ขึ้นเว็บ (สำหรับคนดูแล git)
=========================================

1. แตกไฟล์ zip นี้ทับที่โฟลเดอร์เว็บ — โฟลเดอร์เดียวกับที่มีไฟล์ news.html
   (ตอบ "แทนที่ไฟล์เดิม / Replace" ได้เลย)
2. ในโฟลเดอร์เว็บ สั่ง:
     git add .
     git commit -m "อัปเดตข่าวสาร"
     git push

ไฟล์ที่อยู่ใน zip
  news/news-index.js  = ข้อความ/ลำดับ/พาธรูปของทุกข่าว (เขียนทับของเดิม)
  news/current/...    = รูปของข่าวปัจจุบัน (3 ข่าวที่โชว์หน้าข่าวสาร)
  news/archive/...    = รูปของข่าวย้อนหลัง

หมายเหตุ
  - zip จะมีเฉพาะ "รูปที่เพิ่งใส่ใหม่" ส่วนรูปเดิมที่มีอยู่ในเว็บแล้วไม่ต้องส่งซ้ำ
  - ถ้าย้ายข่าวจากปัจจุบัน -> ย้อนหลัง รูปเดิมจะยังอยู่โฟลเดอร์เดิมและใช้งานได้ปกติ
  - แก้ข่าวครั้งต่อไป เปิด admin/news-admin.html แล้วทำแบบเดิม

# NAVIGATION SYSTEM (เมนูนำทาง)

**พื้นหลังหน้า = ขาว** ทุกหน้า · **ยกเว้นหน้า About Us** (`scroll-site/index.html` — โฮม COOKIEVERSE ยังเป็นธีมส้ม)
**แถบเมนู (tab) = สีส้มตลอดเวลา** ทุกหน้า (ทั้งตอนอยู่บนสุดและตอนเลื่อน)

## กติกาสี
- พื้นหน้า: ขาว ← ผ่าน `theme-white.css` (products/brands/news/contact) · oem-guide ขาวจาก inline เอง
- แถบเมนู: ส้มเสมอ — ค่าสีส้มของ nav ใน `style.css` **ฮาร์ดโค้ด** (`#F07800`, scroll/dropdown/mobile = `#D05E00`)
  ไม่ผูกกับ `var(--og*)` เพราะ `theme-white.css` เปลี่ยน `--og*` เป็นแดง → ถ้าใช้ var แถบจะกลายเป็นแดง
- `theme-white.css` **ไม่ override nav** แล้ว (ลบส่วน `#g-nav` ออก) เพื่อให้แถบส้มโผล่บนพื้นขาว

## ทุกหน้าใช้เมนูชุดเดียวกัน
- **สแตนดาร์ด (`#g-nav`)**: `products.html` · `brands.html` · `news.html` · `contact.html` (พื้นขาว + `theme-white.css`)
- **โฮม / About Us** `scroll-site/index.html`: ธีมส้ม COOKIEVERSE · เมนูผ่าน `.site-header` (สไตล์ท้าย `scroll-site/css/cookieverse.css`)
- **OEM** `oem-guide.html`: พื้นขาว + accent ส้ม · เมนูผ่าน `nav#navbar` (สไตล์ + `navSearch()` inline)
- **โลโก้**: รูป `img/logo-vfoods.png` (ครอปจาก 1920² → 1659×793) สูง 46px ในแถบเมนู

## โครงสร้างแถบเมนู (ซ้าย · กลาง · ขวา)
- **ซ้าย** — โลโก้ `.nav-logo` = "วีฟู้ดส์" + badge แดง `.nav-logo-badge` (VFOODS)
- **กลาง** `.nav-links` (เมนูอังกฤษ ตัวพิมพ์ใหญ่):
  - News & Activities → `news.html`
  - **Products ▾** → hover dropdown 9 หมวดหมู่ (`products.html#<id>`)
  - **Our Brands ▾** → hover dropdown 12 แบรนด์ (`brands.html`)
  - OEM Engagement Guide → `oem-guide.html`
  - About Us → `scroll-site/index.html#about-us`
  - Contact Us → `contact.html`
- **ขวา** — ช่องค้นหา `.nav-search`

## Dropdown = hover mega-menu (CSS-only)
- โผล่เมื่อ hover (`.nav-item:hover .nav-dropdown`) — ไม่พึ่ง JS
- ซ่อนเริ่มต้น `opacity:0; visibility:hidden` + "invisible bridge" (`::before`) กันเมาส์หลุด
- Grid: Products = `.mega` (2 คอลัมน์), Brands = `.mega-brands` (3 คอลัมน์)

## ช่องค้นหา (`.nav-search`)
- พิมพ์คำ + Enter → `products.html?q=<คำค้น>`
- `main.js` → `navSearch()` + `applyProductSearch()` อ่าน `?q=` แล้วกรองการ์ดสินค้าตาม **ชื่อ/แบรนด์**
  (ซ่อนหมวดที่ไม่มีผล + แสดงแบนเนอร์ `#searchBanner`)
- โฮม/OEM มี `navSearch()` inline (redirect ไป products)

## เวลาแก้เมนู
แก้ `<nav>` + `.nav-mobile` ให้ **เหมือนกันทุกไฟล์** (active: `main.js` เติมให้อัตโนมัติจาก URL)

# PERFORMANCE CONVENTIONS (โหลดไว)

- **ฟอนต์**: โหลดผ่าน `<link rel="preconnect">` + stylesheet ใน `<head>` ของแต่ละหน้า
  (เลิกใช้ `@import` ใน `style.css` เพราะ render-blocking + โหลดต่อกันเป็นทอด ๆ)
- **backdrop-filter**: ลด blur ของ nav `28px → 14px` (blur เปลือง GPU มากตามค่ารัศมี)
- **รูปภาพ**: `loading="lazy"` + `.webp` ทุกใบในหน้า products
- แนวทาง: FPS สูง, animation ลื่น, GPU accelerated, responsive (ตามหัวข้อ PERFORMANCE ด้านบน)

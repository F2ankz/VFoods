ข่าวย้อนหลัง

0

ข่าวเก่าที่ยังเปิดอ่านได้จากหน้า “ดูข่าวย้อนหลังทั้งหมด” (รูปเก็บใน news/archive/)

เลือกข่าวทางซ้ายเพื่อแก้ไข หรือกด “+ เพิ่มข่าวใหม่”

วิธีใช้

  1. เลือกข่าวทางซ้าย (หรือกด + เพิ่มข่าวใหม่) แล้วพิมพ์หัวข้อ / วันที่ / เนื้อข่าว
  2. กดกล่องอัปโหลดเพื่อ ใส่รูปปก และ ใส่รูปเพิ่มได้หลายรูป (ลากรูปมาวางก็ได้) — โปรแกรมย่อรูปให้อัตโนมัติ
  3. ข่าวปัจจุบันเก็บได้ 3 ข่าว ถ้าเกินให้กด ↓ ย้ายไปข่าวย้อนหลัง ที่ข่าวเก่าสุด
  4. กด 📦 ส่งออกเป็น .zip → ได้ไฟล์ news-update-วันที่.zip
  5. ส่งไฟล์ zip ให้คนดูแลเว็บ → แตกไฟล์ทับที่โฟลเดอร์เว็บ (โฟลเดอร์ที่มี news.html) → git add . && git commit && git push

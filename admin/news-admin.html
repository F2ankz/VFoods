ยังไม่ได้เปิดไฟล์ — กด "เปิดไฟล์ news-data.js" แล้วเลือกไฟล์ในโฟลเดอร์เว็บ (D:\VFOOD\news-data.js)

รายการข่าว

พรีวิวบนหน้าเว็บ

นี่คือหน้าตาจริงของการ์ดในส่วน "ข่าวสารบริษัท" บนหน้า news.html (กริดแนวนอน 2 แถว ต่อจากฟีด Facebook) — การ์ดที่อยู่บนสุดของรายการทางซ้าย = การ์ดแรกที่โชว์

วิธีใช้งาน
1. กด "📂 เปิดไฟล์ news-data.js" แล้วเลือกไฟล์ news-data.js ที่อยู่ในโฟลเดอร์เว็บ (เปิดครั้งเดียวต่อรอบการแก้ไข)
2. แก้ไข / เพิ่ม / ลบ / สลับลำดับข่าวทางซ้าย — พรีวิวทางขวาจะอัปเดตให้ทันที
3. กด "💾 บันทึก" เพื่อเขียนทับไฟล์ news-data.js โดยตรง (เบราว์เซอร์จะถามสิทธิ์ครั้งแรกที่บันทึก)
4. ถ้าเบราว์เซอร์ไม่รองรับการบันทึกโดยตรง (เช่น Firefox) ให้ใช้ "⬇️ ดาวน์โหลดไฟล์" แล้วนำไฟล์ที่ได้ไปแทนที่ news-data.js เดิมเอง
5. เว็บไซต์เป็นไฟล์สแตติก — หลังบันทึกแล้วต้อง commit + push ขึ้น GitHub อีกครั้งเพื่อให้เว็บจริงอัปเดต (บอก Claude ให้ "commit push deploy" ได้เลย)

# VFoods News Updater (.exe)

โปรแกรมลงข่าวหน้าเว็บ VFOODS แบบดับเบิลคลิกใช้งานได้เลย — ไม่ต้องส่ง .zip ให้ใครอีก

## สำหรับคนลงข่าว

1. ดับเบิลคลิก **`VFoods-News.exe`** ที่โฟลเดอร์เว็บ (โฟลเดอร์เดียวกับ `news.html`)
2. โปรแกรมจะเปิดหน้าลงข่าวในเบราว์เซอร์ให้เอง
3. แก้ข้อความ / ใส่รูป ตามปกติ
4. กด **🚀 อัปโหลดขึ้นเว็บจริง** — จบ รอ 1–2 นาที ข่าวขึ้นเว็บ
5. ปิดหน้าต่างสีส้มของโปรแกรมเมื่อใช้เสร็จ

ปุ่มอื่น
- **💾 บันทึกลงเว็บ** — เขียนไฟล์ลงโฟลเดอร์เว็บอย่างเดียว ยังไม่ push (ไว้ตรวจก่อน)
- **📦 ส่งออกเป็น .zip** — วิธีเดิม ใช้ได้อยู่ เผื่อเครื่องนั้นไม่มี git

ครั้งแรกที่เปิด ถ้าโปรแกรมหาโฟลเดอร์เว็บไม่เจอ จะให้เลือกเอง แล้วจำไว้ให้
(เก็บไว้ที่ `%APPDATA%\VFoodsNews\config.json` — เปลี่ยนได้จากปุ่ม "เปลี่ยนโฟลเดอร์เว็บ")

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `vfoods_news.py` | ตัวโปรแกรม — เว็บเซิร์ฟเวอร์ 127.0.0.1 + หน้าต่างควบคุม (tkinter) + สั่ง git |
| `build.bat` | สร้าง `.exe` ใหม่ด้วย PyInstaller แล้วคัดลอกไปวางที่โฟลเดอร์เว็บ |
| `vfoods.ico` | ไอคอนโปรแกรม (สร้างจาก `img/logo-vfoods.png`) |
| `../../admin/news-admin.html` | หน้า UI ลงข่าว — ไฟล์เดิม เพิ่มปุ่มบันทึก/อัปโหลดเมื่อเปิดผ่านโปรแกรม |

หน้าเว็บกับโปรแกรมคุยกันผ่าน 3 เส้นทางนี้

| เส้นทาง | ทำอะไร |
|---|---|
| `GET /__api/ping` | บอกว่าเปิดผ่านโปรแกรมอยู่ + โฟลเดอร์เว็บคือที่ไหน + มี git ไหม |
| `POST /__api/save` | เขียนไฟล์ลงโฟลเดอร์เว็บ (อนุญาตเฉพาะใต้ `news/` เท่านั้น) |
| `POST /__api/publish` | `git add news/` → `commit` → `push` |

เซิร์ฟเวอร์ผูกกับ `127.0.0.1` พอร์ตสุ่ม เครื่องอื่นในเน็ตเวิร์กเข้าไม่ได้
และเขียนไฟล์ได้เฉพาะในโฟลเดอร์ `news/` — พาธที่ออกนอกนั้นถูกปฏิเสธ

## สร้าง .exe ใหม่

ดับเบิลคลิก `build.bat` (ต้องมี Python 3 ติดตั้งไว้) หรือสั่งเอง:

```bash
python -m PyInstaller --noconfirm --onefile --windowed --name "VFoods-News" --icon vfoods.ico --add-data "vfoods.ico;." vfoods_news.py
```

แก้หน้า UI ไม่ต้อง build ใหม่ — โปรแกรมอ่าน `admin/news-admin.html` จากโฟลเดอร์เว็บสด ๆ
build ใหม่เฉพาะตอนแก้ `vfoods_news.py` เท่านั้น

ตัว `.exe` กับโฟลเดอร์ `build/` `dist/` ไม่ได้ commit ลง git (อยู่ใน `.gitignore`)
